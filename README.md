# Citizens Financial Group (citizens-financial-group)
Citizens Financial Group is one of the oldest and largest financial institutions in the United States, providing retail and commercial banking products and services to individuals, small businesses, middle-market companies, and large corporations through Citizens Bank and its subsidiaries.

## APIs

### Citizens Open Banking API
The FDX-aligned API surface launched in Q1 2025 that gives business, commercial, wealth, and private-banking customers a single endpoint to share account balances, transactions, and other financial data with authorized third-party platforms.

**Human URL:** [https://developer.citizensbank.com/](https://developer.citizensbank.com/)

#### Tags:

 - Accounts, Balances, FDX, Open Banking, Transactions

### Citizens Accounts API
Authorized retrieval of Citizens Bank customer account and transaction information for use in third-party financial applications and aggregation platforms.

**Human URL:** [https://developer.citizensbank.com/api](https://developer.citizensbank.com/api)

#### Tags:

 - Accounts, Balances, Banking, Transactions

### Citizens Statements API
Authorized retrieval of Citizens Bank customer monthly statements for personal financial management and document workflows.

**Human URL:** [https://developer.citizensbank.com/api](https://developer.citizensbank.com/api)

#### Tags:

 - Banking, Documents, Statements

### Citizens ATM Locator API
Search for Citizens Bank ATMs throughout the USA using zip code, street address, or geographical coordinates.

**Human URL:** [https://developer.citizensbank.com/](https://developer.citizensbank.com/)

#### Tags:

 - ATM, Geo Search, Locator

### Citizens Branch Locator API
Search for Citizens Bank branches throughout the USA using zip code, street address, or geographical coordinates.

**Human URL:** [https://developer.citizensbank.com/](https://developer.citizensbank.com/)

#### Tags:

 - Branch, Geo Search, Locator

### Citizens Pay API
Citizens Pay is the buy-now-pay-later embedded financing platform offered by Citizens Bank. The Citizens Pay developer portal exposes APIs for merchant integration, underwriting, and installment-loan lifecycle management.

**Human URL:** [https://developer-citizenspay.citizensbank.com/](https://developer-citizenspay.citizensbank.com/)
